# Making the Portfolio Its Own Workspace

> Independent project | 2026

## Idea

Most portfolio sites hide their implementation behind a polished surface. This site makes the implementation part of the experience.

The file Explorer comes from the real repository structure. Monaco displays the source files. The resume opens in the same editor area.

## Source Control story

The Source Control view adds a second layer to the idea. Git history becomes a visual language for education, work, teaching, and projects.

The graph stays concise because a real Git graph is concise. Each changed Markdown file contains the longer account.

## Design constraint

The interface follows the visual language of VS Code. The goal is recognition, not a loose developer-themed imitation.

That constraint affects spacing, density, icons, hover states, selection, tabs, and the relationship between the sidebar and editor.

## Result

The portfolio behaves like a workspace that explains itself. A visitor can read the short profile or inspect the files behind each chapter.
