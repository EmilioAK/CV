# Independent Projects

Independent projects let me explore product questions that do not fit inside coursework or professional delivery.

## Current projects

### [Macsights](macsights.md)

Macsights is a native macOS gameplay recorder and review tool. It combines video with searchable game events on the playback timeline.

### [Repository-shaped CV](cv-site.md)

This portfolio uses its real repository as the interface. The Explorer, editor, resume preview, and Source Control story all come from the same source tree.

## Why these projects belong together

Both projects turn hidden state into something that a person can inspect.

Macsights connects recorded media with structured game events. The CV site connects a career story with the files and history behind it.

The implementation differs, but the product instinct is similar. A useful interface makes the underlying system legible.
