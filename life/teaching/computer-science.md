# Teaching Computer Science

> Teaching Assistant | Vrije Universiteit Amsterdam | 2024 - 2025

## Courses

I supported Operating Systems, Web Technology, and the Systems Programming Project.

I led web technology classes of 30 students. I also supported an Operating Systems course with more than 400 enrolled students.

The material included C, UNIX, JavaScript, Node.js, REST APIs, and asynchronous programming.

## Improving the explanation

Teaching showed me that knowing an answer is different from explaining it. A useful explanation needs the correct level of detail and a concrete trace.

I rewrote several chapters of the Systems Programming Project manual. The revisions made difficult material clearer for first-time students.

Students responded positively, and the instructors retained the revisions for later cohorts.

## Removing setup friction

I built a Docker development environment for students who used macOS. It gave them a consistent environment for systems projects.

This work connected communication with engineering. The explanation and the tool solved different parts of the same problem.
