# First Program and The Odin Project

> 2019 - 2022

In November 2019, I wrote [mentalcalcpractise](https://github.com/EmilioAK/mentalcalcpractise), a small Python tool for practising mental arithmetic. It shuffled questions, timed correct answers, and restarted after a mistake.

The next day, I created my [first Odin Project repository](https://github.com/EmilioAK/google-homepage). I continued through its projects and algorithms. Each repository turned a new concept into working software that I could inspect and improve.

By 2022, I wanted to understand computing in more depth. I moved from Sweden to Amsterdam to study Computer Science.
