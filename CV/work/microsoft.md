# Cloud Architecture at Microsoft

> Cloud Solution Architect Intern | Amsterdam | September 2025 - February 2026

I joined Microsoft in a customer-facing role that combined discovery, architecture, implementation, and technical communication.

A customer needed to connect an external AI agent with Microsoft Teams and Microsoft 365. I designed and shipped a proxy-agent architecture for the first customer. The design was then reused across two more customer engagements.

I became the main technical contact for the follow-on work and packaged the approach for colleagues. The project connected one customer solution to a reusable delivery pattern.
