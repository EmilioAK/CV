# My Story

I wrote my first Python program in 2019, then continued through The Odin Project. That path led to university, teaching, Microsoft, and production software at Capisoft.

I now work as a Software Engineer at Capisoft. I also study Computer Science at Vrije Universiteit Amsterdam.

My work centers on systems that cross difficult boundaries. Recent examples include accounting integrations, durable email delivery, cloud agent integrations, and native macOS capture.

The Source Control graph presents this path as a repository. Each commit marks a decision, role, or project that changed the direction of my work.
