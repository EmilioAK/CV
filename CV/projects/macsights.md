# Macsights

> Independent project | 2026

Macsights is a native macOS gameplay recorder and review tool. It records video with game events, then shows those events as searchable markers on the playback timeline.

The app uses Swift, SwiftUI, ScreenCaptureKit, AVFoundation, and VideoToolbox. Recording packages keep their metadata beside the media, so the app can rebuild its library from the files.

The capture system handles game restarts, lost capture targets, multiple media segments, validation, and storage limits. The project combines a product that I want to use with direct systems and reliability work.
