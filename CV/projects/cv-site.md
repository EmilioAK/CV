# Repository-shaped CV

> Independent project | 2026

This site uses its real repository as the interface. The Explorer shows the source tree, Monaco opens its files, and the resume appears in the same editor area.

Source Control turns the career thread into a compact Git graph. Each history item opens the Markdown file behind that part of the story.

The interface follows VS Code closely in its spacing, icons, tabs, selection, and navigation. The repository is both the content and the way to inspect it.
